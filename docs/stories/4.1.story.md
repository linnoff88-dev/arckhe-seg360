## Description

As a consumer,
I want to pay for my insurance plan via Pix or credit card,
so that I can complete the purchase quickly and securely.

## Acceptance Criteria

1. [x] Pagina de checkout com resumo do plano selecionado: coberturas, valor mensal
2. [x] Modelo Payment no Prisma: id, userId, quoteId, method (PIX/CARD), amount, status, gatewayId, paidAt, createdAt
3. [x] Para Pix: gerar QR Code e codigo copia-cola (mock gateway)
4. [x] Selecao de metodo de pagamento (Pix ou Cartao)
5. [x] POST /api/payments cria pagamento, POST /api/payments/:id/confirm confirma
6. [x] Tela de confirmacao com status (aguardando pagamento PIX com spinner)
7. [x] Tratamento de erros (cotacao expirada, pagamento duplicado)
8. [x] Logging de transacoes via NestJS Logger
9. [x] 4 testes unitarios para PaymentService
