# Story 1.1: Project Scaffolding & CI/CD

## Status: Done

## Story

**As a** developer,
**I want** a fully configured monorepo with CI/CD pipeline,
**so that** the team can develop, test and deploy with confidence from day one.

## Acceptance Criteria

1. Monorepo criado com workspaces: `apps/web` (Next.js 14+), `apps/api` (NestJS), `packages/shared`
2. TypeScript configurado em todos os workspaces com strict mode
3. ESLint + Prettier configurados com regras compartilhadas
4. PostgreSQL e Redis configurados via Docker Compose para desenvolvimento local
5. Prisma configurado com schema inicial (modelo User basico) e primeira migracao executada
6. GitHub Actions pipeline: lint → test → build em PRs
7. README com instrucoes de setup local (npm install, docker compose up, prisma migrate)
8. Health check endpoint (`GET /api/health`) retornando status 200 com informacoes de versao e conectividade do banco
9. Pagina inicial do Next.js renderizando com layout basico (header, footer, slot de conteudo)

## Dev Notes

### Estrutura do Projeto (de docs/architecture/11-unified-project-structure.md)

```
seg360/
├── .github/workflows/          # CI/CD
│   ├── ci.yml                  # Lint → Test → Build
│   └── deploy.yml              # Deploy staging/production
├── apps/
│   ├── web/                    # Next.js 14+ frontend (porta 3000)
│   │   ├── src/app/            # App Router pages
│   │   ├── src/components/     # React components
│   │   ├── src/hooks/          # Custom hooks
│   │   ├── src/services/       # API client layer
│   │   ├── src/stores/         # Zustand stores
│   │   ├── src/lib/            # Utilities
│   │   └── src/styles/         # Global CSS
│   └── api/                    # NestJS backend (porta 3001)
│       ├── src/common/         # Guards, filters, pipes, decorators
│       ├── src/modules/        # Feature modules
│       ├── src/prisma/         # Schema, migrations, seed
│       ├── src/config/         # App configuration
│       └── src/main.ts
├── packages/shared/            # Shared types & utils
│   └── src/types/, constants/, validations/, utils/
├── docker-compose.yml          # PostgreSQL 16 + Redis 7
├── .env.example
├── package.json                # Root com workspaces
├── turbo.json                  # Turborepo config
└── tsconfig.base.json          # Shared TS config
```

### Coding Standards (de docs/architecture/16-coding-standards.md)

- **Naming:** Componentes PascalCase, arquivos kebab-case, APIs kebab-case, DB snake_case
- **URLs em portugues:** `/painel`, `/corretor`, etc. Codigo em ingles
- **Type Sharing:** Tipos compartilhados DEVEM estar em `packages/shared/src/types/`
- **Environment Variables:** Backend via `@nestjs/config` ConfigService, Frontend via `NEXT_PUBLIC_*`

### Environment Variables (.env.example)

```bash
# Database
DATABASE_URL=postgresql://seg360:seg360@localhost:5432/seg360

# Redis
REDIS_URL=redis://localhost:6379

# JWT (necessario para Story 1.2, placeholder por enquanto)
JWT_SECRET=dev-jwt-secret-min-32-characters-long
JWT_REFRESH_SECRET=dev-refresh-secret-min-32-chars-long

# Frontend
NEXT_PUBLIC_API_URL=http://localhost:3001/api/v1
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
