## Description

As a consumer,
I want to receive my insurance policy immediately after payment,
so that I know I'm protected right away.

## Acceptance Criteria

1. [x] Modelo Policy no Prisma: id, userId, quoteId, paymentId, policyNumber, status, startDate, endDate, coverageDetails, monthlyPremium
2. [x] Apos confirmacao de pagamento, criar Policy com status ACTIVE
3. [x] Gerar numero de apolice unico no formato SEG360-YYYYMMDD-XXXXX
4. [x] Pagina de confirmacao com dados da apolice: numero, status, vigencia, plano, valor
5. [x] Endpoint GET /api/policies/:id retornando detalhes da apolice
6. [x] Endpoint GET /api/policies listando todas as apolices do usuario
7. [x] 4 testes unitarios para PolicyService (criar, unpaid error, cancelar, wrong user)
