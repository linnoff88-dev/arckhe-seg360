## Description

As a consumer,
I want a step-by-step quotation flow,
so that I can get personalized insurance quotes quickly and easily.

## Acceptance Criteria

1. [x] Wizard em 3 passos: (1) Dados do Imovel, (2) Dados Pessoais, (3) Resultado/Comparacao
2. [x] Passo 1: CEP (pre-preenchido se veio do simulador), tipo de imovel (casa/apartamento), valor estimado
3. [x] Passo 2: Nome completo, CPF, email, telefone com validacao em tempo real
4. [x] Passo 3: Loading spinner, redireciona para comparador de coberturas (Story 3.2)
5. [x] Dados do wizard persistidos no estado (nao perdidos ao navegar entre passos)
6. [x] Indicador de progresso visual mostrando o passo atual
7. [x] Validacao inline em cada campo com mensagens em portugues
8. [x] Botoes "Voltar" e "Proximo" em cada passo
9. [x] Se usuario estiver logado, pre-preencher dados pessoais do perfil
10. [x] Cotacao salva e redirecionada ao comparador com IDs via URL

## Implementation Notes

- Rota: /cotacao com wizard de 3 passos
- CEP pre-preenchido via ?cep=XXXXX searchParams
- Mascaras: CEP (XXXXX-XXX), CPF (XXX.XXX.XXX-XX), Telefone ((XX) XXXXX-XXXX), Valor (R$ com separador de milhar)
- Resultado redireciona para /cotacao/comparar?quotes=id1,id2,id3
- Zustand quote store persiste cotacoes entre wizard e comparador
- Auth store usado para pre-preencher nome e email do usuario logado
