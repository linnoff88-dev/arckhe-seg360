## Description

As a backend developer,
I want an abstraction layer for insurtech partner APIs,
so that the platform can generate quotes from multiple providers through a unified interface.

## Acceptance Criteria

1. [x] Interface `InsurtechProvider` definida em packages/shared com metodos: `getQuotes(params)`
2. [x] Implementacao de provider concreto (MockInsurtechAdapter) com 3 planos (Basico, Completo, Premium)
3. [x] Modelo Quote no Prisma: id, userId, cep, riskLevel, providerName, planName, monthlyPremium, coverageAmount, coverageDetails (JSON), validUntil, createdAt
4. [x] Endpoint `POST /api/quotes` aceitando: cep, propertyType, propertyValue, riskLevel, riskTypes e retornando lista de cotacoes
5. [x] Timeout de 5s por provider com fallback graceful (se um provider falhar, retornar os demais)
6. [x] Logging de chamadas a APIs externas via NestJS Logger
7. [x] Testes unitarios com mocks dos providers (2 testes: geracao de cotacoes e premiums crescentes)
8. [x] Endpoints GET /quotes/:id e GET /quotes (usuario logado) para consulta

## Implementation Notes

- Adapter pattern: InsurtechProvider interface com MockInsurtechAdapter
- Provider timeout via Promise.race (5s)
- Quotes salvas no PostgreSQL via Prisma com validade de 30 min
- POST /quotes e @Public(), GET endpoints exigem JWT
- coverageDetails armazenado como JSON no Prisma (cast via Prisma.InputJsonValue)
