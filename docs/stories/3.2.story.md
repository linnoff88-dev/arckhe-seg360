## Description

As a consumer,
I want to compare coverage plans side by side,
so that I clearly understand what each plan covers and what it doesn't before deciding.

## Acceptance Criteria

1. [x] Pagina `/cotacao/comparar` exibindo cards de planos lado a lado (max 3 desktop, carrossel mobile)
2. [x] Cada card mostra: nome do plano, preco mensal, valor de cobertura, lista de itens cobertos/nao cobertos
3. [x] Itens de cobertura padronizados com checkmark verde e X vermelho
4. [x] Filtro por tipo de cobertura
5. [x] Ordenacao: menor preco, maior cobertura, melhor custo-beneficio
6. [x] Botao "Contratar este plano" em cada card (placeholder alert ate Epic 4)
7. [x] Tooltip explicativo em cada item de cobertura
8. [x] Indicador visual "Mais Popular" ou "Melhor Custo-Beneficio"
9. [x] Estado de loading e estado vazio
10. [x] Link para refazer simulacao de risco

## Technical Notes

- Rota: /cotacao/comparar?quotes=id1,id2,id3 (recebe IDs via URL)
- Usa API GET /api/quotes/:id para carregar cada cotacao
- CoverageCard component reutilizavel
- Zustand quote store para persistir estado entre wizard e comparador
- Mobile: carrossel horizontal com snap scroll
