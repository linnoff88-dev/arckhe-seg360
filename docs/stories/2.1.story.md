# Story 2.1: CEP Risk Data Service

## Status: Done

## Story

**As a** backend developer,
**I want** a service that resolves CEP to risk data,
**so that** the risk simulator can show accurate disaster risk information per location.

## Acceptance Criteria

1. Integracao com API de CEP (ViaCEP) para resolver CEP → bairro, cidade, estado
2. Modelo RiskData no Prisma com campos completos
3. Seed de dados de risco para CEPs de regioes conhecidas (RS, RJ, SP litoral, SC, BA)
4. Endpoint `GET /api/risk/:cep` retornando dados de risco com cache Redis (TTL 24h)
5. Fallback para dados agregados da cidade/estado quando CEP nao tem dados especificos
6. Tempo de resposta < 2 segundos
7. Rate limiting: maximo 30 consultas por IP em 1 minuto
8. Testes unitarios cobrindo: CEP valido com dados, fallback, CEP invalido
